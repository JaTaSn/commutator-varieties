# Commutator varieties

The varieties `V(I_k)` cut out by iterated matrix commutators, and their coordinate rings.

Split out of `ai-workspace/projects/fast-commutators/` on 2026-08-30, and named for the programme
rather than its first instalment: the 3×3 case and other iterated-commutator constructions are
expected here too. At `k = 2`, `n = 2` the object *is* the classical commuting variety in reduced
coordinates, which is the literature this sits in — Motzkin–Taussky, Gerstenhaber, the
Artin–Hochster conjecture, Hreinsdóttir, Knutson.

Not to be confused with `ai-workspace/projects/fast-commutators/`, which is the bilinear-complexity
thread — a different subject that happens to share a parent directory. And note "commutator ideal"
means something else in ring theory (the ideal generated by commutators), which is why this repo is
not called that.

**The project directory stays the working home** — review rounds, working notes and the LOGBOOK live
there, deliberately, since more review is expected. This repo holds the submission-bound artefacts.
